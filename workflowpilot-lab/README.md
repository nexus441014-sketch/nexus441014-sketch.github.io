# WorkflowPilot Lab

Static, English-language affiliate content website starter.

## Deploy to GitHub Pages
1. Create a **public** GitHub repository named `nexus441014-sketch.github.io` (or another name and adjust root-relative links).
2. Upload all contents of this folder to the root of the `main` branch.
3. In repository Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)` and Save.
4. Visit `https://nexus441014-sketch.github.io/`. Publication can take several minutes.
5. Before ASP application: replace the contact placeholder with a working email/form; check legal pages and article accuracy; add additional original articles.

## Notes
- No affiliate tracking links or analytics are included.
- Official product links are non-affiliate.
- No paid services required.
- For project repositories, update all root-relative paths to use the repository prefix or a custom domain.
