## The short version

This site is a set of static pages. It does not ask you to log in, it has no comment
form, and it does not run analytics or advertising scripts at the time of writing.

## What is collected

**By this site: nothing.** No account, no newsletter signup, no tracking script, no
cookies set by us.

**By the hosting provider:** these pages are served by GitHub Pages. Like any web host,
it processes technical request data such as IP addresses in order to deliver the page and
protect the service. That processing is governed by GitHub's own privacy statement, not
by this site.

## Email

If you email the address on the [contact page](/contact.html), your message and address
are held in that mailbox so the exchange can be answered. They are not added to any
mailing list and are not passed to anyone else.

## Links to other sites

Guides here link to railway operators, airports, government bodies and commercial
services. Once you follow a link, that site's own privacy policy applies. We have no
control over, and take no responsibility for, what other sites collect.

## Affiliate links

No affiliate tracking links are installed at the time of writing. If that changes, this
notice and the [affiliate disclosure](/disclosure.html) will be updated first, and any
tracking a partner sets will be described here.

## Changes

If analytics, advertising or any other data collection is ever added, this page will be
updated before it goes live, with the date of the change.
